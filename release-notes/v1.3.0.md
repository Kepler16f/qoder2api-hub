# v1.3.0 — 开箱即用桌面客户端

本版本把 Qoder2API-Hub 从「脚本 + 浏览器看板」升级为**跨平台桌面应用**：窗口内直接内嵌完整 Web 看板，功能与网页版 100% 对等。网关本体（COSY 签名、设备指纹、签到福利、双区路由）与上游 v1.2.17 保持一致，零协议改动。

## ✨ 桌面客户端

- **内嵌看板**：账号管理、OAuth 一键授权、签到与福利中心、模型清单、用量指标、实时日志，全部在应用窗口内完成，不依赖外部浏览器
- **五类设备全覆盖**：Windows x64 / Windows ARM64（**原生**，非仿真）/ macOS Apple Silicon / Linux x64 / Linux ARM64
- **系统托盘**：关闭或最小化窗口收缩到托盘（应用图标，非 Python 默认图标）；左键显示/收起，右键菜单；真正退出在托盘菜单
- **开机自启**：写入当前用户自启动项（HKCU Run / LaunchAgent / XDG autostart，无需管理员），开机静默进入托盘
- **看板内设置**：托盘与开机自启开关在看板「设置」页的「桌面客户端」区块内直接切换（仅内嵌壳中显示）
- **窗口尺寸记忆**：关闭时记住大小，下次按上次尺寸启动
- **深色模式跟随系统**：标题栏（DWM）与看板内容同步切换
- **优雅停机**：退出时优雅停止网关，6 秒兜底强杀，不留残留进程

各平台内嵌实现：Windows 为自研纯标准库 ctypes **WebView2 原生宿主**（clr_loader/pythonnet 与 QtWebEngine 均无 win-arm64 支持，故手写 COM）；macOS 用 pywebview（WKWebView）；Linux 用 PySide6 + QtWebEngine；内嵌不可用时自动回退控制台 + 浏览器。

## 🐛 问题修复

- **修复关窗后进程无痕消失**（表现为"网关崩溃"）：WebView2 `WebMessageReceived` 的 COM 回调栈上调用 tkinter（包括 `root.after`）会破坏当前线程的 Python 线程状态，触发 `Fatal PyEval_RestoreThread: thread state is NULL`。现回调内仅入队，由主循环轮询消费
- **修复托盘线程启动即崩**：`GetModuleHandleW` 未声明 restype，64 位句柄被截断后传入 `CreateWindowExW` 触发 `OverflowError`（冻结环境句柄高位随机命中）
- **修复托盘图标显示为 Python 默认图标**：改用 `CreateIconFromResourceEx` 解析内置应用 .ico，不再从 python.exe 提取
- 兼容 Python 3.13+ 移除的 `ctypes.wintypes.GUID / WNDCLASSW`（托盘模块自带结构体定义）

## 📦 下载与安装

| 文件 | 适用 |
|---|---|
| `Qoder2API-Hub-setup-windows-x64.exe` | Windows 10/11 x64（按用户安装，无需管理员） |
| `Qoder2API-Hub-setup-windows-arm64.exe` | Windows on ARM（Surface Pro X / Snapdragon 笔记本，原生） |
| `Qoder2API-Hub-macos-arm64.dmg` | Apple Silicon Mac（拖进 Applications） |
| `qoder2api-hub-linux-x64.deb` | 主流发行版 x64（glibc ≥ 2.28） |
| `qoder2api-hub-linux-arm64.deb` | ARM64 Linux（glibc ≥ 2.39，如 Ubuntu 24.04+） |

- **Windows**：双击安装，默认装到 `%LOCALAPPDATA%\Programs\Qoder2API-Hub`，可选桌面快捷方式，不创建开始菜单文件夹。SmartScreen 提示时点「更多信息 → 仍要运行」（未购代码签名证书的通病）。静默部署：`...setup.exe /VERYSILENT /LANG=chinese`
- **macOS**：DMG 拖入 Applications，首次右键 →「打开」绕过 Gatekeeper；仍被拦则 `xattr -cr /Applications/Qoder2API-Hub.app`
- **Linux**：`sudo dpkg -i qoder2api-hub-linux-*.deb`，装完在应用列表启动
- 首次打开看板的面板密码是 `admin`，请立即在「设置」页修改

详细说明（数据目录、源码运行、构建方式）见 [desktop/README.md](desktop/README.md)。
