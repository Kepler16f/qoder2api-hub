# v1.3.2 — 传输韧性、额度实时化与桌面体验修复

本版本聚焦三类"看不见但天天遇到"的问题：**上游网络抖动不再变成 502**、**账号剩余积分自动保持最新**、**桌面壳四处顽固交互缺陷一次修清**。API 协议零改动（网关本体 1.2.17 → 1.2.20）。

> 说明：v1.3.1 曾作为内部构建（未公开发布），其内容已全部包含在本版本中。
> **Linux 安装包本轮暂缓发布**：体积优化已就位（见下），待独立验证后将单独发版。

## 🐛 上游传输韧性（网关 1.2.18）

此前上游网络短暂抖动时，客户端会收到 502，报错为 `transport transient: <urlopen error [WinError 10061] 由于目标计算机积极拒绝>`；更麻烦的是本机代理开关怎么调都无法恢复，只能重启应用。两处修复：

- **出站不再被"启动瞬间"的代理状态绑架**：`urllib` 的默认 opener 会在进程首次请求时把系统代理设置缓存到进程结束——代理软件随后退出或换端口时，全部上游调用会一直撞死在死端口上（WinError 10061），用户侧改注册表、开关系统代理都无效。现改为**逐请求实时解析代理状态**（`UpstreamOpener`），TUN / 系统代理 / 直连三种形态可随时切换、**无需重启进程**；特殊部署可用环境变量 `QD_PROXY_UPSTREAM_PROXY` 显式指定代理出口。
- **全池传输故障不再过早放弃**：原来单账号瞬时重试 2 次（1s/2s 退避）、逐号轮换约 30 秒即向客户端返回 502，扛不过上游 1 分钟级别的拒连/断流风暴。现在全部账号均因传输层故障失败时，退避 15 秒后**整池重扫**（最多 2 轮），把上游瞬时抖动挡在网关内侧；重扫期间一旦出现 HTTP 响应或频控，说明上游已恢复，立即按既有语义上抛——**401/429/其他 4xx 的处理路径完全不变**。

## 📊 额度（credits）实时化（网关 1.2.19）

此前看板上的剩余积分只在手动点「刷新积分」按钮、或签到/活动流程后才回读一次；看板的 15 秒轮询只是反复渲染同一份持久化旧值——打完几轮对话，余额可能几小时不动。

- **读数触发 + 单飞后台刷新**：看板每 15 秒轮询的 `GET /accounts` 顺带检查额度新鲜度，超过 TTL（默认 60 秒，`QD_CREDITS_TTL` 可调）即在后台补一次，**不阻塞响应**，下一轮轮询即见新值；
- **消耗后加速**：每次对话完成消耗额度后，该账号被标记，约 5 秒后即可触发回读——实测对话结束后 **5 秒**内余额自动更新（400 → 389）；
- **有界重试，不放大请求**：同一账号受单飞锁与最小间隔（5 秒）约束，刷新失败不会跟随轮询频率放大；停用账号按 5×TTL 低频补一次；
- **按区域过滤**：看板当前视图是哪个区域就补哪个区域的账号，`realm=all` 时全部；
- 手动「刷新积分」按钮与签到/活动后的刷新路径保持不变，仍是强制回读。

## 🖥️ 桌面壳修复（网关 1.2.20）

- **屏蔽返回手势**：触控板横扫、鼠标侧键、Alt+← 会把内嵌 WebView 退回"网关开启动画"页——那里只有等待逻辑，界面就此卡死无法回主界面。现于 WebView 就绪时写入 `IsSwipeNavigationEnabled=FALSE`（关闭横扫与鼠标侧键导航）与 `AreBrowserAcceleratorKeysEnabled=FALSE`（关闭 Alt+←/→、F5 等浏览器快捷键），手势路径全部封死，看板自身刷新不受影响。实现为纯 Settings 写入、**零事件回调注册**——实测事件回调方案在进程拆卸阶段会被随机投递触发 `PyEval_RestoreThread` 必崩（即使回调体为空），已弃用。
- **托盘菜单新增「重启」**：一键重启整个客户端。实现"先停后拉"：优雅停网关 → 拉起新实例 → 旧进程退出；新实例起网关前会等端口真正空闲（最长 10 秒）。过程中修复了一个隐蔽坑：PyInstaller onefile 会通过 `_MEIPASS2` 环境变量让子进程复用父进程的解包目录——父进程退出即删除之，导致子进程 `ModuleNotFoundError: select` 直接起不来；现重启子进程剥离全部 `_MEIPASS*`/`_PYI_*` 标记。端到端实测：spawn → 端口交接 → 子进程健康 → 旧进程干净退出。
- **修复托盘菜单点击后残留桌面**：托盘右键菜单从 Tk 弹出改为**原生 Win32 菜单**（在托盘线程内 `TrackPopupMenu`），并按 MSDN KB135788 补齐 `SetForegroundWindow` + 事后 `PostMessage(WM_NULL)`——点击菜单外任意位置（包括托盘收起）都会正常消失。菜单配色经 `SetPreferredAppMode` 跟随系统深浅色。
- **检查更新指向本仓库**：更新检查 API 从上游 `shuishuipingan/qoder2api-hub` 改为 `Kepler16f/qoder2api-hub-desktop`，看板里的"前往 Releases 下载升级"链接随之指向本仓库 Releases；版本对比改用**桌面发行版版本**（`APP_VERSION`，随 release tag 走），不再拿网关版本线错位比较，避免永久误报。

## 📦 Linux 包体积优化（本期暂缓发 Linux 包）

PySide6 hook 会把整棵 Qt 树收进包，Linux deb 达 ~230MB。现按**实际 ELF 依赖闭包**裁剪（`desktop/prune_linux.py`，fail-open：解析失败一律保留）：

- 删除未被壳引用的 Qt 模块库（3D/图表/多媒体/定位/虚拟键盘等 100 个 `libQt6*.so`）、壳未 import 的 PySide6 绑定、整个 qml 目录、DevTools 资源包；
- WebEngine locale 只保留 en-US + zh-CN，Qt 翻译只保留 qtbase 中英文；
- WebEngine 渲染链全部保留（QtWebEngineProcess / icudtl.dat / 资源包 / 平台插件）；
- 开启 `strip` 剥离符号表。

归档体积实测 **232.8 → 174.9MB（-25%）**，最终 deb 预计 ~180MB。本轮 release 不附带 Linux 包，优化后的包将在独立的 Linux 版本中发布。
